# 项目需求

## 供应商调研知识库管理系统

### 项目概述
- 项目名称：供应商调研知识库管理系统
- 启动日期：2026-04-13
- 当前阶段：需求分析

### 核心目标
- 建立供应商调研知识库
- 实现供应商信息的系统化管理
- 提供高效的调研数据检索和分析功能

### 假设功能需求

#### 1. 供应商信息管理
- 供应商基本信息录入与编辑
- 供应商分类管理
- 供应商资质文档管理
- 供应商状态跟踪（活跃、待审核、黑名单等）

#### 2. 调研问卷管理
- 问卷模板创建与管理
- 问卷发布与回收
- 问卷响应统计分析
- 问卷版本控制

#### 3. 知识库管理
- 调研资料上传与分类
- 全文检索功能
- 知识库标签管理
- 知识版本控制与历史记录

#### 4. 数据分析与报表
- 供应商评分与排名
- 调研数据可视化
- 自定义报表生成
- 数据导出功能

#### 5. 用户权限管理
- 多角色支持（管理员、调研员、查看者等）
- 细粒度权限控制
- 操作日志记录
- 审批流程管理

#### 6. 飞书集成
- 飞书账号登录（SSO）
- 飞书机器人消息推送
- 飞书多维表格数据同步
- 飞书审批流程集成
- 飞书日历日程提醒
- 飞书文档链接关联

### 技术栈假设
- 前端：React + TypeScript + shadcn/ui
- 后端：Node.js + Express 或 Python + FastAPI
- 数据库：PostgreSQL
- 缓存：Redis
- 全文检索：Elasticsearch
- 文档存储：MinIO 或 AWS S3

### 用户角色和权限假设
- **系统管理员**：完整系统权限
- **调研员**：创建问卷、管理供应商、上传知识
- **审核员**：审核供应商、审核知识内容
- **查看者**：只读访问权限
