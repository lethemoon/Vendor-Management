## 用户故事

### 核心用户故事

**As a** 高校应届毕业生，  
**I want** 注册账号并登录系统，  
**So that** 我可以使用论文降重和AIGC检测功能。

### 次要用户故事

1. **As a** 已注册用户，  
   **I want** 查看和修改个人信息，  
   **So that** 保持我的账户信息准确。

2. **As a** 系统管理员，  
   **I want** 查看用户注册和使用情况，  
   **So that** 了解系统运营状态。

## 明确不做的内容（本期）

### 不包含的功能

1. **会员订阅系统** - 延迟到P1阶段，本期只提供基础免费功能
2. **用户权限管理** - 本期只有普通用户角色，管理员功能延迟到P1阶段
3. **用户头像上传** - 本期使用默认头像，自定义头像延迟到P1阶段
4. **手机号验证码发送** - 本期只实现邮箱验证，手机验证码延迟到P1阶段
5. **多设备登录管理** - 本期不限制多设备登录，延迟到P1阶段
6. **账号注销功能** - 延迟到P1阶段

### 技术债务说明

- 本期不实现手机号验证码功能，后续需要集成短信服务商（阿里云短信）
- 本期不实现微信登录，后续需要申请微信开放平台账号
- 本期不实现会员系统，后续需要集成支付系统（支付宝/微信支付）

## 用户流程

### 注册流程

```
用户访问注册页
  ↓
选择注册方式（邮箱/手机号）
  ↓
填写注册信息
  ├─ 邮箱注册：邮箱 + 密码 + 确认密码
  └─ 手机号注册：手机号 + 验证码 + 密码
  ↓
提交注册
  ↓
系统验证
  ├─ 格式校验
  ├─ 重复检测
  └─ 密码强度检查
  ↓
创建账号
  ↓
自动登录
  ↓
跳转到工作台
```

### 登录流程

```
用户访问登录页
  ↓
选择登录方式（邮箱/手机号）
  ↓
填写登录信息
  ├─ 邮箱登录：邮箱 + 密码
  └─ 手机号登录：手机号 + 验证码
  ↓
提交登录
  ↓
系统验证
  ├─ 账号存在性检查
  ├─ 密码验证
  └─ 失败次数检查
  ↓
生成JWT Token
  ↓
跳转到工作台
```

## 验收标准

### 功能验收

- [ ] 用户可以通过邮箱注册账号
