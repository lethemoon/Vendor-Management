## 用户故事

### 核心用户故事

**As a** 高校应届毕业生，  
**I want** 上传论文文本并进行智能降重处理，  
**So that** 我可以降低论文重复率，顺利通过学校查重检测。

### 次要用户故事

1. **As a** 已注册用户，  
   **I want** 查看论文的重复率和AIGC疑似率，  
   **So that** 我了解当前论文的风险等级。

2. **As a** 已注册用户，  
   **I want** 选择不同的改写强度和风格，  
   **So that** 我可以根据需要调整降重效果。

3. **As a** 已注册用户，  
   **I want** 查看详细的查重报告和高重复段落标记，  
   **So that** 我可以有针对性地修改高风险段落。

## 功能清单

### P0功能（MVP必需）

| 功能点 | 描述 | 验收标准 | 成功指标 |
|-------|------|---------|---------|
| 文本上传 | 支持粘贴文本、上传Word/PDF文件 | 1. 支持文本直接粘贴<br>2. 支持Word文件解析(.docx)<br>3. 支持PDF文件解析<br>4. 文件大小限制10MB<br>5. 字数限制5万字 | 上传成功率 ≥ 95% |
| 智能分析 | 自动识别高重复段落并标记 | 1. 显示整体重复率<br>2. 标记高重复段落(红色)<br>3. 标记中等重复段落(黄色)<br>4. 显示各段落的原始重复率 | 分析准确率 ≥ 85% |
| 一键改写 | 对选中段落进行智能改写 | 1. 保持原意不变<br>2. 降低重复率≥30%<br>3. 改写后文本通顺自然<br>4. 提供多个改写版本可选 | 降重成功率 ≥ 80% |
| 降重报告 | 生成完整的降重报告 | 1. 显示原文vs改写对比<br>2. 标注修改位置和类型<br>3. 统计总体降重效果<br>4. 支持导出PDF/Word | 报告生成时间 < 5秒 |
| 历史记录 | 保存所有降重操作历史 | 1. 记录原文、改写结果、时间戳<br>2. 支持查看历史记录<br>3. 支持重新编辑 | 数据保存成功率 100% |

### P1功能（核心功能阶段）

| 功能点 | 描述 | 验收标准 |
|-------|------|---------|
| 多轮优化 | 支持对同一段落多次改写 | 提供3个以上不同版本的改写结果 |
| 风格选择 | 学术风格、口语风格等 | 至少提供3种改写风格 |
| 批量处理 | 同时处理多个段落 | 支持选择多个段落批量改写 |

## 明确不做的内容（本期）

### 不包含的功能

1. **AIGC降痕功能** - 本期只做降重，AIGC检测单独作为P0功能
2. **实时协作编辑** - 本期不支持多人同时编辑
3. **在线文档存储** - 本期不提供云端存储，数据本地化
4. **引用格式自动修正** - 延迟到P1阶段
5. **多语言支持** - 本期仅支持中文论文
6. **图片表格识别** - 本期仅支持纯文本处理
7. **移动端完整体验** - 本期优先PC端，移动端简化版延后

### 技术债务说明

- Word/PDF解析使用第三方库，复杂格式可能解析不完美
- AI改写依赖外部API（DeepSeek/硅基流动），需考虑API成本和延迟
- 大文本处理可能存在性能瓶颈，后续需优化

## 用户流程

### 主流程

```
用户访问论文降重页面
  ↓
上传或粘贴论文文本
  ↓
系统自动分析
  ├─ 分句分词
  ├─ 计算重复率
  └─ 标记高风险段落
  ↓
用户选择需要改写的段落
  ↓
点击"一键改写"
  ↓
AI生成改写结果（多个版本）
  ↓
用户选择最佳改写版本
  ↓
应用到原文
  ↓
生成降重报告
  ↓
导出或继续编辑
```

## 验收标准

### 功能验收

- [ ] 用户可以通过粘贴或上传方式提交论文文本
- [ ] 系统能够自动计算并显示论文重复率
- [ ] 高重复段落能够被准确标记和突出显示
- [ ] 用户可以选择段落进行一键智能改写
- [ ] 改写后重复率能够降低30%以上
- [ ] 能够生成包含原文/改写对比的详细报告
- [ ] 所有操作都有历史记录可追溯

### 性能验收

- [ ] 文本分析响应时间 < 3秒（5000字以内）
- [ ] 单段改写响应时间 < 5秒
- [ ] 报告生成时间 < 2秒
- [ ] 支持5000字以上的长文本处理

### 质量验收

- [ ] 改写后文本保持原意不变
- [ ] 改写后文本语法正确、表达流畅
- [ ] 无明显AI生成痕迹（通过人工抽检）
- [ ] 重复率降低效果符合预期
