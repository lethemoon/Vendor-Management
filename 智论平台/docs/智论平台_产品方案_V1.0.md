## 第一篇 产品概述

### 第1章 产品定位与目标

#### 1.1 产品定位

智论平台是一款面向大学生、研究生的AI论文写作助手，提供论文去重、AIGC降痕、知识库管理、多学科图表生成等核心功能。

- **目标用户**：本科生、研究生、青年学者
- **核心价值**：提升论文写作效率，确保学术规范
- **产品形态**：Web端 + 移动端H5

#### 1.2 市场分析

国内论文检测市场以CNKI、维普、万方为主导，检测服务需求旺盛。现有工具存在以下痛点：

- 信息密度过高，用户体验差
- AI功能融合不足，缺乏智能化辅助
- 引用管理功能薄弱，格式支持不全
- 图表生成功能缺失，需多工具切换

#### 1.3 产品目标

| 阶段 | 周期 | 目标 | 核心指标 |
|-----|------|------|---------|
| MVP验证 | 2周 | 验证核心功能可行性 | 100种子用户 |
| 核心功能 | 3周 | 完善降痕+知识库 | 500注册用户 |
| 产品化 | 4周 | 图表生成+移动端 | 2000注册用户 |
| 规模运营 | 持续 | 用户增长与变现 | 10000付费用户 |

## 第二篇 功能需求

### 第3章 核心功能需求

#### 3.1 论文去重与AIGC降痕

这是智论平台的核心功能，帮助用户降低论文重复率和AIGC检测率。

**用户场景：**

- 用户上传论文文本，系统自动识别高重复段落
- AI生成改写建议，用户可逐段采纳或调整
- 实时预估降重效果，支持多轮优化

**功能清单：**

| 功能点 | 描述 | 优先级 |
|-------|------|-------|
| 文本分析 | 分句、分段、重复率计算 | P0 |
| 智能改写 | 同义替换、句式重组、段落重构 | P0 |
| 降重率预估 | 基于检测算法模拟预估 | P0 |
| 改写历史 | 保存改写记录，支持回溯 | P1 |
| 风格选择 | 学术风格、口语风格等 | P1 |
| AIGC检测模拟 | 模拟主流检测平台结果 | P0 |
| 对抗改写 | 针对AIGC检测的优化改写 | P0 |

#### 3.2 知识库与文献管理

用户可建立个人知识库，管理参考文献，实现智能引用。

**功能清单：**

| 功能点 | 描述 | 优先级 |
|-------|------|-------|
| 文献导入 | 支持PDF、Word、网页导入 | P0 |
| 元数据提取 | 自动识别标题、作者、期刊等 | P0 |
| 分类管理 | 文件夹、标签、收藏夹 | P1 |
| 全文检索 | 基于RAG的语义检索 | P1 |
| 多格式引用 | GB/T 7714、APA、MLA等 | P0 |
| 一键插入 | 在编辑器中插入引用 | P1 |
| 引用溯源 | 点击引用跳转原文 | P1 |

#### 3.3 多学科图表生成

支持生成流程图、架构图、CAD图、统计图等多种图表类型，满足不同学科需求。

## 第三篇 引用规范

### 第5章 引用文献标准

#### 5.1 标准选型依据

智论平台面向国内高校用户，必须支持GB/T 7714-2015作为默认标准。同时支持APA 7th、MLA 9th、Chicago 17th等国际格式，满足投稿国际期刊的需求。

#### 5.2 GB/T 7714核心规范

**两种正文标注体系：**

- 顺序编码制：`[1]`、`[1,3]`、`[1-3]`，理工科常用
- 著者-出版年制：`(张三, 2020)`、`(Smith et al., 2020)`，社科类常用

**文献类型标识代码：**

| 代码 | 文献类型 | 代码 | 文献类型 |
|-----|---------|-----|---------|
| [M] | 专著/图书 | [J] | 期刊论文 |
| [D] | 学位论文 | [C] | 会议论文集 |
| [N] | 报纸文章 | [R] | 报告 |
| [S] | 标准 | [P] | 专利 |
| [EB/OL] | 在线电子资源 | [DB/OL] | 在线数据库 |

**著录格式示例：**

```
[1] 作者. 文章标题[J]. 期刊名, 年, 卷(期): 页码.
[2] 作者. 论文题目[D]. 保存地: 保存单位, 答辩年份.
```

#### 5.3 多格式对比

| 维度 | GB/T 7714 | APA 7th | MLA 9th | Chicago 17th |
|-----|-----------|---------|---------|--------------|
| 正文标注 | [1] 或 (作者, 年) | (作者, 年) | (作者 页码) | 脚注或(作者, 年) |
| 文献类型标识 | 必须有 | 无 | 无 | 无 |
| 作者格式 | 前3位+等 | 姓+名缩写 | 姓+名全写 | 姓+名全写 |
| 书名斜体 | 不斜体 | 斜体 | 斜体 | 斜体 |
| 适用学科 | 中国所有学科 | 心理学、社科 | 文学、艺术 | 历史、哲学 |

## 第四篇 视觉设计

### 第6章 设计理念与策略

#### 6.1 品牌定位

智论平台品牌关键词：专业、可信、高效、年轻。目标用户为大学生、研究生、青年学者，设计风格应兼顾学术严谨与现代活力。

#### 6.2 设计原则

- **清晰优先（Clarity First）**：学术工具核心是信息清晰
- **渐进展示（Progressive Disclosure）**：复杂功能分层展示
- **AI透明（AI Transparency）**：AI过程可见可控
- **一致性（Consistency）**：跨平台体验统一
- **无障碍（Accessibility）**：符合WCAG 2.1 AA标准

#### 6.3 竞品视觉分析

| 产品 | 主色调 | 风格 | 优势 | 不足 |
|-----|-------|------|------|------|
| 知网CNKI | 深蓝 | 传统门户 | 权威感强 | 信息过载 |
| 万方 | 浅蓝 | 传统数据库 | 覆盖全学科 | 界面老旧 |
| NoteExpress | 灰蓝 | 桌面软件 | 功能专业 | 缺乏现代感 |
| Grammarly | 绿色+白 | 现代SaaS | 体验流畅 | 中文支持弱 |
| Notion | 黑白灰 | 极简 | 灵活强大 | 学术功能弱 |

#### 6.4 差异化设计策略

- 在蓝色主色基础上引入琥珀色(Amber)作为强调色，形成独特辨识度
- 暗色模式优先设计（2026年趋势，竞品均未提供）
- AI功能以Copilot侧边栏模式集成，区别于竞品的全自动模式
- 大量留白+信息密度控制，解决竞品信息过载痛点

### 第9章 动效规范

### 第11章 风险与合规

明确产品定位为辅助工具，用户对最终内容负责。提供使用边界指引，避免学术不端。

#### 11.2 数据安全

- 数据加密：传输加密、存储加密
- 访问控制：权限管理、操作日志
- 合规认证：等保备案、隐私政策

#### 11.3 用户责任边界

| 责任方 | 责任内容 |
|-------|---------|
| 平台 | 格式准确性、功能稳定性、数据安全 |
| 用户 | 引用内容恰当性、学术诚信、最终审核 |
